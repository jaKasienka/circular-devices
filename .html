Circular Devices Project Rules

🎯 Project Overview & Core Mission

You are building Circular Devices, a mobile-first recycling ecosystem centered around hardware lifecycle diagnostics. The app runs on a smartphone to dynamically scan and evaluate other (typically older/secondary) devices. Your task is to take functional lo-fi wireframes/user flows and refactor them into crisp, production-grade components using the design tokens defined below and referencing the visual look established on the Hi-Fi Home screen.

Design System Token Mapping

  • Light Mode Primitives: @/tokens/brandcyan.light.primitive.tokens.json
  • Light Mode Semantics: @/tokens/brandcyan.light.semantic.tokens.json
  • Dark Mode Primitives: @/tokens/brandcyan.dark.primitive.tokens.json
  • Dark Mode Semantics: @/tokens/brandcyan.dark.semantic.tokens.json
  • Typography: @/tokens/brandcyan.typography.styles.tokens.json

Token & Theme Rules:

  1. Dark Theme (Default): Use token aliases from brandcyan.dark.semantic.tokens.json (resolving against brandcyan.dark.primitive.tokens.json).
  2. Light Theme (.light / @media): Use token aliases from brandcyan.light.semantic.tokens.json (resolving against brandcyan.light.primitive.tokens.json).
  3. Typography: Use the fonts and exact line-height definitions from brandcyan.typography.styles.tokens.json. Never use default CSS/Tailwind line-heights.
  4. Font Weight Mapping: "Regular" -> 300 (font-normal), "Medium" -> 400 (font-medium), "SemiBold" -> 500 (font-semibold), "Bold" -> 600 (font-bold).

📈 Refactoring Logic

When processing wireframe mockups or legacy functional views:

  1. Enforce Absolute Mobile-First Layouts: Standardize default frame structures around standard compact mobile viewports (e.g., width 375px, fluid vertical bounds).
  2. Apply Auto Layout Structural Integrity: Translate wireframe floating elements into strict nested flexboxes or relative linear layouts.
    • Text boundaries must use Fill Container or fluid flex constraints to avoid overflow breaks.
    • Paragraph layouts must use Auto Height boundaries with ample line heights to balance the wide geometries of Montserrat Alternates.
  3. Token Mapping Translation: Automatically strip placeholder standard generic system layouts (e.g., Arial, Inter, standard 12px) and map them to their corresponding brandcyan- semantic tokens in tokens/brandcyan.typography.styles.tokens.json
  4. Preserve User Flow and Functional Intent: The layout might look messy in lo-fi, but do not drop buttons, data inputs, or tracking logic. Respect the interactive steps completely.

1. Typography Scales

  • Display / Headline (Nico Moji): Playful, geometric, wide, futuristic. Use as h1. Use with positive tracking for readability on massive displays/numerical callouts.
  • Headline / Title / Label (Oxanium): Sharp, tech-inspired, angular. Highly visible for structural indicators, buttons, tags, and components.
  • Body (Montserrat Alternates): Round and soft, echoing the geometry of Nico Moji while maintaining excellent structural line padding.

Refer to @/tokens/brandcyan... for precise structural code mappings.

🎨 Global Design Tokens Configuration

Always map UI components exclusively to these design mappings. DO NOT invent arbitrary font sizes, weights, or families. Ask if you think it's necessary.

Stack & Code Quality:

  • Use React 18, TypeScript, React Router 6, Vite, and Tailwind CSS.
  • Prefer pnpm for dependency management and project scripts.
  • Keep TypeScript strict: avoid any, type component props, and use type-only imports where appropriate.
  • Build small functional components and extract shared UI only when it removes meaningful duplication.
  • Reuse components from client/components/ui/ and utilities such as cn() before creating alternatives.
  • Keep pages in client/pages/ and declare routes in client/App.tsx above the catch-all route.
  • Use the @/ alias for client imports and @shared/ for shared types.
  • Use theme tokens from @/tokens/ (and their generated CSS variables in client/global.css / tailwind.config.ts); avoid duplicating raw colors or hex values.
  • Preserve the mobile-first Circular Devices design and verify layouts at 375 × 812 pixels.
  • Store permanent images and icons in public/assets/; do not commit expiring Figma asset URLs.
  • Use semantic HTML, accessible labels, meaningful image alt text, and visible keyboard focus states.
  • Add Express API endpoints only when logic must run server-side, such as secrets or protected database work.
  • Keep API routes under /api/ and share request/response types through shared/.
  • Avoid unrelated refactors, unnecessary dependencies, and generated placeholder content.
  • After substantive changes, run pnpm typecheck and the relevant tests or build.
